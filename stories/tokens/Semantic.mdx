# Semantic & Role Tokens

La capa semántica es el nivel intermedio entre los primitivos de color y los componentes: **Primitivos → Roles → Componentes**.

Los componentes deben consumir estos tokens para que el cambio de tema y el modo oscuro funcionen de forma automática.

---

## Cómo funciona

```
data-mode="dark"  →  [data-mode="dark"] { --ds-color-surface: #1B1916; … }
OS dark mode      →  @media (prefers-color-scheme: dark) { … }
data-mode="light" →  [data-mode="light"] { … }  ← sobreescribe la media query
```

Los tokens de acción (`--ds-color-action-*`) se vinculan a `--ds-primary-color-*` del stylesheet activo y cambian automáticamente con el tema.

## Activar modo oscuro

```html
<!-- Explícito -->
<body data-mode="dark"> … </body>

<!-- Forzar modo claro sobre preferencia del SO -->
<div data-mode="light"> … </div>

<!-- Automático — respeta prefers-color-scheme sin atributo -->
```
