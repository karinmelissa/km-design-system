# Typography

Dos familias de tipografía. **Titillium Web** para UI, etiquetas y cuerpo — limpia y humanista. **Baloo 2** para títulos, display y el logotipo — redondeada y expresiva.

> **Regla de pairing:** usa Baloo para display/headings, Titillium para el resto. Nunca uses Baloo en párrafos largos de cuerpo.
